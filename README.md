# To Eman ❤️ — Abdallah's Heart

An interactive, cardiology-inspired romantic web experience built with love by Abdallah for Eman.

## Features
- **The Anatomical Heart Visualizer**: Visual representation of the human heart where Abdallah provides the beat, but Eman occupies 100% of all chambers, arteries, and vessels.
- **Dynamic Occupancy Scanner**: Real-time fluid animation scanning every chamber and confirming Eman's total occupancy.
- **Real-time ECG Rhythm**: Live electrocardiogram waveform responding to simulated heart rate (BPM).
- **Interactive Anatomical Hotspots**: Clickable cards revealing love notes for the Aorta, SA Node, Ventricles, and Apex.
- **Runaway "No" Button**: A playful button that dodges whenever Eman tries to decline.
- **Celebration Fireworks & Love Letter**: Confetti cannons and a heartfelt letter from Abdallah.
- **Romantic Audio Synthesizer**: In-browser Web Audio API romantic chord progression.

Live URL: https://abdallah-raafat.github.io/eman-heart/
